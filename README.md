# SMM Project (Monorepo)

This repo contains both the frontend and backend in one place:

- `frontend/` — React/Vite frontend (smm_web_frontend)
- `backend/` — Node.js backend (SMM-backend1-main)

## Setup

### Backend
```
cd backend
cp .env.example .env   # fill in your real values
npm install
npm run dev  # or: npm start (check backend/package.json for exact script)
```

### Frontend
```
cd frontend
cp env.example .env    # fill in your real values
npm install
npm run dev
```
